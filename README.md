# AVENORA

A frontend starter for AVENORA, a global crowdfunding platform.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Current scope
This starter contains a responsive public homepage, sample campaign cards, a campaign detail route, and a start-fundraiser information page. Campaign content is demonstration data only.

## Important
This is a frontend prototype. It does not yet include user accounts, a database, identity verification, escrow/custody, payment processing, withdrawals, or production compliance controls. Do not collect real donations or sensitive documents until those systems and applicable legal requirements are implemented and reviewed.
